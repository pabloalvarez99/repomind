# mini_js fixture

Committed JavaScript/TypeScript sources for free-path multi-language plumbing.

- Catalog id: `mini_js`
- Question: `Where is foo defined?` → `src/foo.js` with a path:line citation
- Python AST remains the default free path; this fixture only proves a second
  language can be indexed without network, embeddings, or tree-sitter in CI

This is not a code-RAG or multi-language SOTA claim.
